# Research-only canonical v3 static assets

`prepareProductionV3.mjs` prepares an offline runtime directory for later browser qualification. It does not activate AI in the app, publish a classifier, or grant promotion. It reads no model graph, candidate head, final dataset, audio or prediction. It validates the embeddings in the supplied completed extraction reference solely as checkpoint-integrity evidence; real-observation vectors and source records are never copied to the output. An optional startup reference contains only two fixed synthetic software cases and their normalized vectors.

```sh
node ml/browser/prepareProductionV3.mjs --reference COMPLETE_NODE_RUN/embeddings.json --manifest STAGED/manifest.json --output NEW_PARENT/runtime-v3 --cache output/ml-cache --dependencies .
# Optional software startup checks; omit the option to exclude these two assets.
node ml/browser/prepareProductionV3.mjs --reference COMPLETE_NODE_RUN/embeddings.json --manifest STAGED/manifest.json --output NEW_PARENT/runtime-v3-with-self-test --self-test-reference ml/browser/fixtures/self-test-v3-reference.json
node --test ml/browser/prepareProductionV3.test.mjs
```

The output parent must exist; the output directory must not. All input verification and compilation precede output creation, and existing output is never overwritten. The reference must use the current complete Node canonical contract, including source/compiled model-config hashes. The staged manifest must match its recorded SHA and every completed row, including original `source_record` metadata. Every normalized Float32 checkpoint, input identity and repeated PCM/features/embedding digest must pass the existing canonical validator. This detects partial or mismatched references; it is not independent proof that a supplied extraction was executed honestly or that a classifier is accurate.

The packager independently pins the qualified versions and hashes. It verifies the standard ORT Web WASM, loader and bundle; the upstream Transformers.js 4.3.1 browser bundle; model/preprocessor configuration; unchanged canonical encoder, runner and checkpoint validator; unchanged `src/ai/resample.ts` and `model.ts`; and the research integer scorer. TypeScript 7.0.2 compiles the numeric modules without bundling/minification, and their output hashes must equal the fixed qualified bytes. The scorer's source and compiled hashes are separately pinned; no fitted parameters are included. Changed inputs or versions fail rather than updating the contract automatically.

The output contains:

- `canonicalEncoder.mjs`, unchanged; `transformers.web.js`, with only its two external ONNX imports redirected to `./ort.wasm.bundle.min.mjs`.
- The exact standard `ort.wasm.bundle.min.mjs` plus `runtime/ort-wasm-simd-threaded.mjs` and `.wasm`. No alternate WebGPU/asyncify/native graph or runtime is included.
- Exact compiled `app/resample.js`, `app/model.js`, and byte-identical extensionless `app/model`; `integerHeadV3.js` is the separately compiled research scorer.
- Pinned upstream model/preprocessor JSON configuration under `models/REVISION/`; no ONNX weights or classifier head.
- `NOTICES.txt`, full Transformers.js Apache-2.0 license, ONNX Runtime MIT license and unfiltered upstream third-party notices. ORT notice files are preserved from [commit 8d85527a010e294a26b274749f74294b2a32cec5](https://github.com/microsoft/onnxruntime/tree/8d85527a010e294a26b274749f74294b2a32cec5). Inclusion of its broader project notice does not assert that every listed component is in this WASM build. The model-config attribution retains the distinction between the LAION license declaration and the absent separate Xenova declaration.
- `asset-manifest.json`: each emitted asset's SHA256, byte count, MIME and role; extraction-reference hashes/count; numerical dependency pins; packager hash; `activationReady:false` and `promotionAllowed:false`. It contains no clip IDs, vectors or observer data. The manifest does not hash itself.

## Optional synthetic startup reference

`--self-test-reference` adds unchanged `selfTestV3.mjs` and `self-test-v3-reference.json` to the output. Their whole-file SHA256 pins are separate from the unchanged runtime pins. The packager also verifies that the reference's runtime/preprocessing fingerprints match the supplied extraction contract and that its two normalized Float32 vectors match their recorded complete embedding hashes. A modified module, altered/partial reference or dependency mismatch fails before output creation. No synthetic PCM or audio file is copied or generated by the packager.

The generator is pinned to `cf4c6a95f4b5108c4c906829385f062a66ccf363a2ece78c49da31b634af4105`; the 36,622-byte reference is pinned to `6d5414df3b9413283c88f599887d149314c9c8fb189c5324205b452e33a2212d`. It contains a five-second 44.1 kHz square wave and five-second 48 kHz seeded integer noise. The reference retains full input, resampled-PCM, feature and normalized-embedding SHA256s plus two 512-coordinate synthetic vectors. Its provenance records three extractions per case in Node and Chrome with exact stage equality. These are software fixtures, not field recordings, class predictions, training examples or evidence of microphone behavior, accuracy or coverage. A future startup gate should compare hashes without scoring these vectors through a candidate head.

## Future serving and qualification

Treat these as opaque static files. A future Vite `public/` copy may serve them without rebundling, dependency optimization, minification or numeric source edits. No app, package or Vercel configuration is changed by this tool. Serve JS as `text/javascript`, including **extensionless `app/model`**; the unchanged resampler imports `./model`. Serve WASM as `application/wasm` and JSON as `application/json`. Do not let an asset request return the SPA's HTML fallback. The emitted manifest records these requirements; it does not configure the server.

A future caller must bind the same locally served ORT module, preprocessor config, deterministic resampler and raw canonical encoder. It must retain the canonical one-thread/fixed-SIMD/sequential session settings and exact five-second 44.1/48 kHz PCM contract. Numeric assets must be rehashed after serving/building, followed by actual browser golden PCM/features/embedding equality and exact integer-head parity before considering activation. Dataset gates, independent held-out evaluation and field qualification remain separate requirements; packaging alone establishes none of them.

## Minimal future worker pattern — design notes only

Use a separately reviewed **raw static module worker** beside these assets. Create it with an origin-relative URL and `{type:'module'}`; do not import it through a TypeScript source module or a Vite `new URL(..., import.meta.url)` worker transform. Keep its imports relative to that immutable asset directory: `./ort.wasm.bundle.min.mjs`, `./transformers.web.js`, `./canonicalEncoder.mjs`, `./app/resample.js`, and the separate scorer. Both redirected Transformers imports then resolve to the same ORT module instance. A caller must verify served asset hashes against an independently trusted manifest; a manifest supplied alongside arbitrary altered assets is not a trust anchor. Static-path bundler avoidance still needs verification on the built site.

Disable Transformers remote models and browser/FS model caches, and use the pinned local config directory. The previously qualified browser path uses `AutoProcessor.from_pretrained(REVISION, {local_files_only:true})` with `env.localModelPath` set to that directory's parent. Separately fetch the approved audio graph as bytes and verify its pinned SHA before passing it to `createCanonicalEncoder`. Pass absolute same-origin `wasmPaths` URLs for both `runtime/ort-wasm-simd-threaded.mjs` and `.wasm`. This retains exact numeric modules and does not ask a pipeline to choose a native, WebGPU or alternative graph. Graph acquisition is outside this packager.

Before accepting microphone requests, a future worker must run the fixed synthetic input cases and compare complete input/resampled PCM, feature and normalized embedding hashes. A missing asset, unsupported runtime or any mismatch must disable the candidate and expose an unavailable status; it must not silently fall back to another numerical backend. Passing these cases establishes only that those software checks agree. It is not a substitute for the broader golden browser qualification, the fitted head's own integer parity checks, held-out evaluation or independent field evidence.

Send a separate copy of the first five seconds of PCM with the actual sample rate; transferring its buffer must not detach or alter the DSP/report waveform. Serialize requests, retain an epoch/request ID to discard stale results after cancellation, and release the encoder session or terminate the worker when appropriate. Only an independently approved, hash-bound head could later be loaded after all gates pass. These notes add no loader, worker, head or app activation.
