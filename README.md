# TonalWatch

**The ears for the gap.**

Loudoun County's own zoning page admits its noise standard cannot see tonal
noise — the exact sound data center neighbors complain about. TonalWatch
measures A-vs-C weighted sound at once, flags the tonal signature (the gap),
and generates an evidence-grade complaint packet citing the ordinances —
before the county amends its rules in 2027.
